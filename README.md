# PunchClock
Sistema de Ponto

Sistema web para registro de jornada de trabalho. Funcionários registram entradas e saídas por meio de uma interface simples, e o sistema guarda cada batida em um banco de dados PostgreSQL com data e hora. A API em Python valida as regras de registro, como a alternância entre entrada e saída, e disponibiliza o histórico para consulta.

Objetivo

Construir um sistema completo de ponta a ponta, do banco de dados à interface, como projeto de estudo e de portfólio. O foco está em aprender a modelar dados, criar uma API e desenvolver um front-end, com boas práticas de organização.
